# 담기전에 · 번호별 상품 모음

유튜브·인스타그램·스레드 '담기전에' 영상에 나온 상품을 **번호로 찾아 바로 확인하는 모바일 페이지**입니다.

- 주소: https://jihob873-dotcom.github.io/damgijeonepick/
- 수록: 발행이 끝난 회차만 (`queue.json` 기준 `status: published`) — 최신 회차가 위로
- 카드: 회차 번호 배지 · 상품명 · 가격(확인 시점) · 한 줄 포인트 · 구매 전 확인할 점 · 쿠팡 링크
- 검색: 번호(`14`)나 키워드(`세차기`)로 바로 걸러집니다

## 고지

이 페이지의 일부 링크는 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
영상과 사진은 AI로 만든 활용 예시이며 실제 제품 시연이 아닙니다. 가격·후기 수는 상품 확인 시점 기준입니다.

## 갱신 방법

이 저장소의 `index.html`은 손으로 쓰지 않고, 운영 큐(`queue.json`)에서 자동 생성됩니다.
새 회차가 발행되면 작업 환경에서 아래 한 줄로 다시 만들어 올립니다.

```bash
work/damgi-linkhub/build_and_deploy.sh
```
